# Transcode Web UI 规范

## 1. 概述

本规范定义了转码服务的前端管理界面，基于 Vue 3 + Ant Design 实现。前端界面提供转码任务管理、策略管理、进度监控、任务调度等功能，支持 SSE 实时进度推送，提供友好的用户体验。

## 2. 功能需求

### 2.1 任务管理
- **任务列表**：展示所有转码任务，支持分页、筛选、排序
- **任务详情**：查看任务的详细信息，包括输入输出、转码参数、执行日志等
- **任务创建**：创建新的转码任务，支持选择策略和自定义参数
- **任务取消**：取消正在执行或等待中的任务
- **任务重试**：重试失败的任务
- **任务删除**：删除历史任务记录

### 2.2 策略管理
- **策略列表**：展示所有转码策略，支持分页、筛选、排序
- **策略详情**：查看策略的详细配置
- **策略创建**：创建新的转码策略，支持多步骤配置
- **策略编辑**：编辑现有策略
- **策略删除**：删除策略
- **策略复制**：复制现有策略作为新策略
- **策略导入导出**：导入导出策略配置

### 2.3 进度监控
- **实时进度**：使用 SSE 实时显示转码进度
- **进度条**：显示转码进度百分比
- **转码速度**：显示转码速度（MB/s）
- **剩余时间**：显示预计剩余时间
- **步骤状态**：显示多步骤转码的每个步骤状态

### 2.4 任务调度
- **任务队列**：查看当前任务队列
- **队列管理**：调整任务优先级
- **批量操作**：批量取消、重试任务
- **调度统计**：查看调度统计信息

### 2.5 历史记录
- **历史查询**：查询历史转码任务
- **历史详情**：查看历史任务的详细信息
- **历史统计**：查看历史转码统计信息
- **历史导出**：导出历史记录

### 2.6 参数查看
- **任务参数**：查看任务的输入输出参数
- **转码参数**：查看转码的详细参数
- **执行日志**：查看任务的执行日志
- **错误信息**：查看任务的错误信息

### 2.7 系统监控
- **实例状态**：查看转码服务实例状态
- **队列状态**：查看任务队列状态
- **资源使用**：查看 CPU、内存、磁盘使用情况
- **性能指标**：查看转码性能指标

## 5. 技术实现

### 5.1 技术栈
- **框架**：Vue 3
- **UI 组件库**：Ant Design Vue
- **状态管理**：Pinia
- **路由**：Vue Router
- **HTTP 客户端**：Axios
- **SSE 客户端**：EventSource
- **构建工具**：Vite
- **TypeScript**：TypeScript
- **代码规范**：ESLint + Prettier

### 5.2 核心组件

#### 5.2.1 TaskList
- 功能：任务列表
- 组件：Table、Pagination、Filter、Button、Tag、Progress

#### 5.2.2 TaskDetail
- 功能：任务详情
- 组件：Descriptions、Card、LogViewer、ProgressMonitor

#### 5.2.3 ProgressMonitor
- 功能：进度监控
- 组件：Progress、Statistic、Timeline

#### 5.2.4 StrategyEditor
- 功能：策略编辑
- 组件：Form、Steps、Card、Button

#### 5.2.5 TaskScheduler
- 功能：任务调度
- 组件：Table、Button、Modal

#### 5.2.6 HistoryQuery
- 功能：历史查询
- 组件：Table、DatePicker、Filter

#### 5.2.7 TaskParameters
- 功能：参数查看
- 组件：Descriptions、CodeEditor

### 5.3 状态管理

#### 5.3.1 TaskStore
- 状态：任务列表、当前任务、筛选条件
- 操作：获取任务列表、获取任务详情、创建任务、取消任务、重试任务

#### 5.3.2 StrategyStore
- 状态：策略列表、当前策略
- 操作：获取策略列表、获取策略详情、创建策略、更新策略、删除策略

#### 5.3.3 ProgressStore
- 状态：任务进度、连接状态
- 操作：连接 SSE、断开 SSE、更新进度

#### 5.3.4 SystemStore
- 状态：系统状态、通知
- 操作：获取系统状态、发送通知

### 5.4 API 集成

#### 5.4.1 任务 API
- GET /api/transcode/task：获取任务列表
- GET /api/transcode/task/{id}：获取任务详情
- POST /api/transcode/task：创建任务
- DELETE /api/transcode/task/{id}：取消任务
- POST /api/transcode/task/{id}/retry：重试任务

#### 5.4.2 策略 API
- GET /api/transcode/strategy：获取策略列表
- GET /api/transcode/strategy/{id}：获取策略详情
- POST /api/transcode/strategy：创建策略
- PUT /api/transcode/strategy/{id}：更新策略
- DELETE /api/transcode/strategy/{id}：删除策略

#### 5.4.3 进度 API
- GET /api/transcode/progress/{taskId}/sse：SSE 实时进度推送

#### 5.4.4 系统 API
- GET /api/transcode/system/status：获取系统状态
- GET /api/transcode/system/instances：获取实例状态

## 9. 风险评估

### 9.1 潜在风险
- **SSE 断线**：SSE 连接断开导致进度更新不及时
- **API 延迟**：API 响应延迟导致用户体验差
- **浏览器兼容性**：不同浏览器的兼容性问题
- **性能问题**：大量数据导致页面卡顿

### 9.2 缓解措施
- **SSE 重连**：实现 SSE 断线自动重连
- **API 缓存**：实现 API 响应缓存
- **浏览器测试**：测试主流浏览器的兼容性
- **虚拟滚动**：使用虚拟滚动优化列表渲染性能
