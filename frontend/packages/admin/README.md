## 📖 简介 | Introduction

**Admin** 是 Kitty CMS 的管理后台，基于 Vue 3、Vite、Ant Design Vue 构建，提供用户、配置、内容等管理功能。

**Admin** is the management panel for Kitty CMS, built with Vue 3, Vite, and Ant Design Vue.

---

## 🚀 开发 | Development

```bash
# 在 frontend 根目录
npm run dev:admin
```

默认访问：`http://localhost:3000`

---

## 📦 构建 | Build

```bash
npm run build:admin
```

---

## ⚙️ 配置 | Configuration

- `.env.develop`：开发环境变量
- `config.js`：API 等配置
