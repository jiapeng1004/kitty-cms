## 📖 简介 | Introduction

**Mobile** 是 Kitty CMS 的移动端应用，基于 uni-app 构建，支持 H5、微信小程序、支付宝小程序等多端。

**Mobile** is the mobile application for Kitty CMS, built with uni-app for H5, WeChat Mini Program, Alipay Mini Program, and more.

---

## 🚀 开发 | Development

```bash
# 在 frontend 根目录
npm run dev:mobile      # 默认 H5
npm run dev:mp-weixin   # 微信小程序（在 packages/mobile 下）
```

---

## 📦 构建 | Build

```bash
npm run build:mobile
npm run build:h5
npm run build:mp-weixin
# 其他平台见 package.json scripts
```
